# Cloud Cost 開発計画

最終更新: 2026-08-24

## 目的

Cloudflareを採用する個人・小規模事業者が、請求後ではなく導入前と利用中に費用を判断できるようにする。

## 製品の段階

### Phase 1 — 接続不要の試算

- R2、Workers、D1の公開料金を計算する
- ファイル共有など、用途から入力できる
- 既存のアカウント利用量を手入力して無料枠の競合を反映できる
- 公式料金の更新日と計算根拠を表示する

### Phase 2 — 読み取り専用Cloudflare接続

- Cloudflare OAuth Authorization Code Flowを利用する
- 必須scopeは `Account Analytics: Read` のみに絞る
- アカウントと対象リソースを利用者が選択する
- R2、Workers、D1の集計値をGraphQL Analytics APIから読む
- ファイル本体、オブジェクト名、D1の行データを取得しない
- 接続解除とtoken失効を画面から行える

### Phase 3 — 予測と費用ガード

- 今月実績、月末予測、前月比較
- 高コストなバケット・Worker・DBの特定
- 保存期間変更などの削減シミュレーション
- 50%、80%、100%の予算通知
- Handoffへアップロード前試算と上限停止を組み込む

## 精度の境界

- R2保存料は日次ピークの30日平均で請求されるため、接続版では日次値から計算する。
- GraphQL AnalyticsのR2保持期間は31日。長期比較には日次集計値だけを保存する。
- Cloudflareアカウント全体で共有される無料枠を反映する。
- 税、決済時の為替、Enterprise契約、個別割引、未対応製品は見積り対象外とする。
- 表示は「公式請求」ではなく「推定」とし、単一値に加えて不確実な項目を明示する。
